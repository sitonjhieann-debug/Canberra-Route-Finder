### Project Description
Canberra Route Finder is an interactive web application that demonstrates graph traversal and pathfinding algorithms using a street map of Canberra, Australia.

### Features
- 32 vertices and 46 edges
- Interactive Canberra map
- Uniform Cost Search (UCS)
- Greedy Best-First Search
- A* Search
- Animated exploration and final route visualization
- Route cost and exploration order

### Technologies Used
- Python
- Flask
- HTML
- CSS
- JavaScript

### How to Run

1. Install the required dependencies:

   `pip install -r requirements.txt`

2. Run the application:

   `python main.py`

3. Open your browser and visit:

   `http://127.0.0.1:5000/`

### Purpose
This project demonstrates the practical application of graph data structures and search algorithms in finding routes between locations.
